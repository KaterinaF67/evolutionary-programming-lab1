# Лабораторная работа №1

## Многомерная оптимизация функции HappyCat генетическим алгоритмом

**Дисциплина:** Эволюционное программирование и генетические алгоритмы  
**Группа:** Б24-517  
**Номер в списке:** 25  
**Индивидуальный вариант:** 19  
**Размерность задачи:** 6  

## Что находится в проекте

- `ga.py` — основная реализация генетического алгоритма;
- `experiments.py` — запуск серии экспериментов и построение графиков;
- `Отчет.pdf` — отчёт;
- `results/` — результаты запусков, параметры и графики.

## Что реализовано

В работе используются:

- вещественное представление особи;
- турнирная селекция;
- арифметический crossover;
- гауссовская мутация;
- адаптивное изменение масштаба мутации;
- обработка выхода за границы допустимой области;
- элитизм;
- сравнение с равномерным случайным поиском.

## Основные параметры

| Параметр | Значение |
|---|---:|
| Размерность | 6 |
| Границы поиска | от -20 до 20 |
| Размер популяции | 150 |
| Бюджет вычислений | 30000 |
| Вероятность crossover | 0.90 |
| Основная вероятность мутации | 0.30 |
| Размер турнира | 3 |
| Число элитных особей | 2 |
| Начальный масштаб мутации | 1.0 |
| Конечный масштаб мутации | 0.001 |
| Число независимых запусков | 20 |

## Требования

Python 3.10+.

Необходимые библиотеки:

```bash
pip install numpy pandas matplotlib
```

## Запуск

Проверочный запуск основной реализации:

```bash
python ga.py
```

Полная серия экспериментов:

```bash
python experiments.py
```

После запуска `experiments.py` результаты сохраняются в папку `results`.

## Содержимое папки results

- `parameters.csv` — параметры исследуемых конфигураций;
- `runs.csv` — результаты всех независимых запусков;
- `convergence.png` — график сходимости генетического алгоритма;
- `mutation_comparison.png` — сравнение двух вероятностей мутации;
- `ga_vs_random.png` — сравнение генетического алгоритма со случайным поиском.

## Эксперименты

Для каждой конфигурации выполнено 20 независимых запусков.

Сравнивались:

- генетический алгоритм с вероятностью мутации 0.15;
- генетический алгоритм с вероятностью мутации 0.30;
- равномерный случайный поиск.

Во всех сравнениях использовался одинаковый бюджет вычислений целевой функции.

## Краткий вывод

Генетический алгоритм показал значительно лучшие результаты, чем равномерный случайный поиск.

В проведённой серии запусков конфигурация с вероятностью мутации 0.30 показала более стабильные результаты по среднему значению, медиане и стандартному отклонению.
